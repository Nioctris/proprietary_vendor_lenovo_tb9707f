# Proprietary blobs for the Lenovo Legion Y700 2022 (TB-9707F)

Vendor tree for the LineageOS device tree
[android_device_lenovo_tb9707f](https://github.com/Nioctris/android_device_lenovo_tb9707f).
It holds the 835 blobs listed in `proprietary-files.txt` (in `proprietary/`)
and the makefiles generated by `extract-files.py`.

The base list is Xiaomi `sm8250-common` (kona) filtered against the stock
images, plus the Lenovo delta: Lenovo HIDL services, CS35L45 speaker
protection, Novatek NT36523 touch firmware, QCA6390, AW8697/RichTap haptics,
Dolby, ArcSoft camera algorithms, CamX, SSC sensors and the IPA firmware.
Entries from the Xiaomi list that do not exist on this device are kept in
`proprietary-files.txt` as `# missing: <path>` comments.

## Not stock

Do not regenerate these with a plain `extract-files.py` run:

- Dolby DAP effects, DMS libraries and `libdapparamstorage` are the Motorola
  DAX 3.6 set from `swiitch-OFF-Lab/hardware_dolby` (branch `XiaomiDolby`):
  the stock Lenovo DAX 3.5 DAP ignores parameter writes from the settings app.
- `daxService.apk` is stock with `DaxApplication.ensureVqeAvailabilityForUser`
  patched to `return-void`, re-signed with the platform key (`PRESIGNED`).
